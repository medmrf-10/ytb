# دليل أدوات مستودع `ytb` (`ytb/tools/README.md`)

تحتوي هذه الحزمة على أدوات برمجية مكتوبة بلغة Python 3 (تعتمد حصرياً على المكتبة القياسية Standard Library دون أي مكتبات خارجية) لتنفيذ مراحل توحيد المفرّغات وحل التعارضات وإزالة التكرار وفقاً للخطة المعتمدة في `ytb/PLAN.md`.

---

## 1. محتويات المجلد

| الملف | المرحلة | الوصف والوظيفة |
|---|---|---|
| `common.py` | مشترك | مكتبة مساعدة تحوي الثوابت، والتعابير النمطية (Regexes)، والدوال المشتركة (تطبيع النصوص، استخراج الترويسات، بصمات النصوص، شجرة المجموعات المنفصلة Union-Find، حساب تشابه Jaccard، وجلب طوابع الـ commit). |
| `inventory.py` | P1 | أداة الجرد الشامل لكافة المخازن الخمسة ومجموعات المحاذاة والكتب. تقرأ المصادر قراءة فقط وتستخرج الهويات والترويسات والبصمات وتكتب سجل الجرد والخرائط الأساسية. |
| `resolve.py` | P2 | محرك الحسم وإزالة التكرار: يقوم بربط الدروس عبر معرّف يوتيوب وبصمة النص المطبَّع (Union-Find)، ويكتشف التعارضات ويحسم الفائز حتمياً وفق قواعد القسم 3، ويولد خطة النقل ودفتر الحسم وتقرير التكرار. |

---

## 2. كيفية إعادة تشغيل خط المعالجة (Pipeline)

يتم تشغيل الأدوات بترتيب تسلسلي حتمي من داخل مجلد المستودع:

```bash
# 1. الانتقال إلى مستودع ytb
cd /root/workspace/ytb

# 2. تشغيل مرحلة الجرد P1 (تستغرق ≈ 35 ثانية)
python3 tools/inventory.py

# 3. تشغيل مرحلة الحسم وإزالة التكرار P2 (تستغرق ≈ 6 ثوانٍ)
python3 tools/resolve.py
```

## 3. مخرجات كل مرحلة في `_meta/`

### مخرجات `inventory.py` (P1):
- `_meta/inventory.jsonl`: سجل تفصيلي لكل ملف نصي (8,595 محاضرة + 490 ملفات استبعاد ومحاذاة).
- `_meta/INVENTORY.json`: إحصائيات مجمعة لكل مخزن (الملفات، البصمات الفريدة، الحجم، تغطية المشايخ).
- `_meta/row_map.json`: خريطة ربط السلاسل والصفوف القانونية (دمج `row_ids` و `alias_keys` و `redirects` والصفوف المصنوعة).
- `_meta/sheikh_map.json`: جدول مطابقة أسماء المشايخ وألقابهم مع المعرّفات اللاتينية الثابتة (Slugs).
- `_meta/excluded.json`: حصر المجموعات المستبعدة (المتون، المحاكاة، كوربوس الكتب).

### مخرجات `resolve.py` (P2):
- `_meta/plan.jsonl`: خطة النقل خطوة بخطوة لكل درس فريد (`lid`, `target`, `winner_record`, `sources`, `variants`, `also_in`).
- `_meta/conflicts.jsonl`: تفاصيل التعارضات النصية الحقيقية الـ 43 بنصوص الفائز والخاسر ونسبة التشابه.
- `_meta/RESOLVE.json`: دفتر الحسم الشامل لكل درس، سبب فوزه، وقائمة النسخ المتطابقة والخاسرة.
- `_meta/DEDUPE_REPORT.md` (ونسخة في جذر المستودع `DEDUPE_REPORT.md`): التقرير التحليلي الكامل باللغة العربية.

## 4. القواعد الصارمة والضمانات

1. **قراءة فقط للمصادر**: الأدوات لا تُعدّل ولا تنقل ولا تحذف أي بايت داخل مستودعات `hawshat` أو `des` أو `irth`.
2. **الكتابة الذرية (Atomic Writes)**: كافة الملفات تُكتب عبر ملفات مؤقتة `.tmp` ثم تُستبدل ذرياً لتجنب تلف البيانات.
3. **الحتمية والثبات (Deterministic & Idempotent)**: إعادة التشغيل تنتج نفس الدفتر والمخرجات بدقة 100%.
