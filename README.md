# ytb — مستودع مفرّغات المحاضرات

الهدف: مكان واحد يجيب على سؤال: **«ما محتوى الشيخ الفلاني الذي لديه تفريغ؟»**

## التنظيم المعتمد
- مجلد لكل شيخ.
- داخل مجلد الشيخ: مجلد لكل سلسلة.
- داخل مجلد السلسلة: ملفات دروسها المفرّغة (وفهارس السلسلة).

## الحالة
المستودع قيد البناء. الخطة التنفيذية تُحفظ محلياً في `PLAN.md` داخل هذا المستودع بعد اعتماد المالك.

## قواعد
- لا تُحذف مواد من المستودعات المصدر (hawshat / irth / des) — النسخ فقط.
- كل درس يحتفظ بمعرّفه: معرّف فيديو يوتيوب أولاً، ثم رقم الصف + رقم الدرس.
