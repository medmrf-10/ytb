# ytb — مستودع مفرّغات المحاضرات

المستودع الموحّد لكافة تفريغات الدروس والمحاضرات الصوتية والمرئية، يجيب بأمر واحد على سؤال: **«ما محتوى الشيخ الفلاني الذي لديه تفريغ؟»**

---

## 1. الإحصاءات العامة

- **إجمالي المشايخ المسجلين**: 29 شيخاً (17 شيخاً لديهم تفريغات حالياً + مجلد للدروس غير المنسوبة).
- **إجمالي السلاسل المفرغة**: 147 سلسلة.
- **إجمالي المحاضرات المفرغة**: 4,049 محاضرة فريدة.
- **إجمالي الحجم النصي**: 88,914,853 حرفاً.
- **محاسبة المصادر**: تم استيعاب 8,595 ملف محاضرة من المخازن الخمسة دون أي فقد (4,049 فائز + 4,502 تكرار مدمج + 44 بديل خاسر في `_variants/`).

## 3. كيفية الاستعلام

يمكن الاستعلام عن محتوى أي شيخ مباشرة من سطر الأوامر عبر أداة `ask.py` التي تقرأ الفهارس محلياً:

```bash
# استعلام بالاسم أو اللقب بالعربية
python3 tools/ask.py البوطي
python3 tools/ask.py "أحمد السيد"

# أو بالمعرف اللاتيني
python3 tools/ask.py said-bouti

# إخراج بصيغة JSON للأتمتة والتطبيقات
python3 tools/ask.py البوطي --json
```

## 4. هيكل المستودع والملفات

```
ytb/
  README.md                       # دليل المستودع الرئيسي
  catalog.json                    # الفهرس العام الشامل لكافة المشايخ والسلاسل
  COVERAGE.md                     # تقرير تفصيلي بنسب التغطية والإجماليات المعلنة
  <sheikh-slug>/                  # مجلد الشيخ (slug لاتيني مجمّد)
    _sheikh.json                  # بطاقة تعريف الشيخ وألقابه وإحصاءاته
    _index.json                   # فهرس سلاسل ودروس الشيخ
    README.md                     # صفحة الشيخ بالعربية
    <row-key>/                    # مجلد السلسلة (معرّف السلسلة القانوني)
      _series.json                # بطاقة بيانات السلسلة والمصدر والإجمالي المعلن
      _index.json                 # فهرس محاضرات السلسلة
      README.md                   # صفحة السلسلة بالعربية وقائمة دروسها
      <NNN>_<vid>.txt             # نص المحاضرة الفائز (بايتات المصدر كما هي)
      <NNN>_<vid>.meta.json       # البيانات الوصفية ومصادر التفريغ والجودة
      _variants/                  # النصوص البديلة الخاسرة في حال وجود تعارض نصي
  tools/                          # أدوات الفهرسة والاستعلام والتحقق (Python stdlib)
  _meta/                          # دفاتر المحاسبة والتحقق وتقارير إزالة التكرار
```

## 5. قواعد وثوابت

1. **المصادر للقراءة فقط**: لم يُعدّل أو يُحذف أي بايت في مستودعات `hawshat` أو `des` أو `irth`.
2. **ثبات الهوية**: كل درس يحمل معرّف يوتيوب أولاً `yt:<vid>`، ثم رقم الصف والدرس `rn:<row>:<n>`.
3. **الأسماء القانونية**: كافة الأسماء العربية للشيوخ والسلاسل مأخوذة حصراً من السجل المعتمد `registry.json` دون أي ارتجال.
